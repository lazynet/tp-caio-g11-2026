# Las tres capas

La slide de síntesis es una pirámide: prevención como base, detección en el
medio, respuesta arriba.[^m3u1]

| Capa | Técnicas |
|---|---|
| Prevención | Filtrado, validación, DLP, anonimización, cifrado |
| Detección | Monitoreo continuo, auditoría, alertas |
| Respuesta | Red teaming, corrección, entrenamiento adversario |

# Conclusiones clave

- **La amenaza es real:** prompt injection y jailbreaks son técnicas activas y en evolución; requieren defensas igualmente dinámicas.
- **Los datos merecen protección máxima:** una estrategia DLP robusta es indispensable donde haya información sensible.
- **El red teaming es proactivo:** atacar el sistema antes que los adversarios es la estrategia más efectiva para una IA resiliente.[^m3u1]
